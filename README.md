# Tomato Plant Disease Detection 

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/tjin9/tomato-disease-detection/blob/main/Tomato_Disease_Detection.ipynb)

A complete deep learning **predictive application** built to classify tomato leaf health conditions and diseases across 10 distinct categories. The project leverages Transfer Learning with **MobileNetV2** for feature extraction and provides an interactive web interface built with **Streamlit**.


## Features
- **10 Classification Categories**: Detects healthy leaves as well as 9 common diseases (such as Early Blight, Late Blight, Bacterial Spot, Yellow Leaf Curl Virus, etc.).
- **Transfer Learning**: Built using MobileNetV2 trained on the PlantVillage dataset for high accuracy.
- **Interactive Web App**: Allows users to upload tomato leaf images and get instant predictive results with confidence scores.

## Technologies Used
- **Google Colab** & **Python**
- **TensorFlow / Keras** (MobileNetV2 for Feature Extraction)
- **Streamlit** (Interactive Web App Interface)
